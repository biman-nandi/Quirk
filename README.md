# Quirk --- Modern Ecommerce Storefront

Quirk is a modern, responsive ecommerce storefront built with Next.js,
TypeScript, and Tailwind CSS. It focuses on a clean shopping experience,
intuitive navigation, and a responsive interface across desktop, tablet,
and mobile devices.

## Tech Stack

-   Next.js 15 (App Router)
-   TypeScript
-   Tailwind CSS v4
-   React Icons
-   Next.js local fonts (`next/font/local`)

## Features

-   Fully responsive design
-   Dynamic mega menu for product categories
-   Search bar and shopping icons
-   User profile dropdown with account navigation
-   Custom local fonts
-   Next.js App Router and React Server Components

## Getting Started

### 1. Clone the repository

``` bash
git clone https://github.com/your-username/quirk-ecommerce.git
cd quirk-ecommerce
```

### 2. Install dependencies

``` bash
npm install
```

### 3. Run the development server

``` bash
npm run dev
```

### 4. Open the application

Go to <http://localhost:3000> in your browser.
